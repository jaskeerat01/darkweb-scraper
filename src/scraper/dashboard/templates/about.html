About

Scope, privacy, and operating notes for this local dashboard.

scope

This dashboard displays alerts collected by the Dark Web Threat Intelligence Engine. It is intended for authorised defensive security, threat intelligence, and educational research only.

Onion targets are crawled through Tor. Clearnet targets, when explicitly enabled and allowlisted, are also fetched through the Tor SOCKS5 proxy, never directly from this host.

Do not use this tool to access, store, or distribute illegal material. You are responsible for complying with applicable law and target terms of service.

data flow

The scraper writes to a local SQLite database in WAL mode. This dashboard opens that database read-only and renders it server-side.

No telemetry, analytics, external fonts, CDNs, or third-party scripts are used. The dashboard makes no outbound network requests.

Session authentication is optional. When enabled, the access token is exchanged for a signed, HttpOnly, SameSite=Strict cookie.

operating notes
  • Clearnet targets see a Tor exit IP and may be blocked by the destination.
  • Plain HTTP is readable and modifiable by an exit node; prefer HTTPS.
  • Source URLs are shown as text, never as clickable links, so the browser does not resolve onion names.
  • Severity and category are deterministic heuristics on top of the local model summary, not model verdicts.
  • The dashboard never exposes Tor control credentials, Telegram tokens, or model paths.
